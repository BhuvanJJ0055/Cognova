===================================================================
Incoming Documents Directory (data/incoming_docs/)
===================================================================

Drop new CSV, JSON, or TXT documents into this directory to trigger
automatic background ingestion into the Cognova Knowledge Base.

Supported formats:
- .csv (columns: question, answer, focus, question_type)
- .json (array of objects with question and answer keys)
- .txt (plain text files containing Q&A pairs or FAQ content)
